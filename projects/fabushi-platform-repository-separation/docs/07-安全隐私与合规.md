# 安全、隐私与合规

- 源仓库和目标仓库均为 public 代码边界；任何 secrets、cookie、签名证书、provisioning
  profile、`.env`、测试账户状态和生产数据库文件都不得迁移。
- 使用最小权限的 GitHub token；仓库创建、push、branch protection 和 secrets 配置分开记录，
  不把 token 写入日志、commit、workflow artifact 或项目记录。
- 目标仓库按平台设置 CODEOWNERS 和 required checks；生产签名只在目标仓库的 CI secrets 中
  读取，不从源仓库复制。
- 第三方代码、字体、模型、音频、经文、Marketplace 包和商店素材在导出前逐项核对 license
  和 provenance；不因为拆仓而扩大分发范围。
- 平台边界扫描必须阻止 `../frontend`、`../mobile`、`../third_party` 等源仓库相对路径在
  目标构建脚本中残留，除非它是明确 pin 的外部依赖。
