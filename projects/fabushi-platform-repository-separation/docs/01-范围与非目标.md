# 范围与非目标

## In scope

- 按平台建立独立 public GitHub 仓库并记录仓库 URL、owner、默认分支和初始 SHA。
- 从 `cbe65975f3c4c077fa64af4171ebe3d2900185ad` 生成平台历史/快照，完成路径保留审计。
- 将共享 Mahayana/Rust/Telegram/Global Dharma 能力从平台仓库边界中独立出来。
- 将 CLI 的命令行入口、TUI 兼容层、harness 和独立 Release 链路从 Core/平台中分离。
- 迁移各平台的 CI、测试、打包、Release、部署、CODEOWNERS 和 README。
- 更新 Desktop/移动端/Browser updater、Worker 路由和依赖引用，使其不再指向源仓库相对路径。
- 在所有目标仓库验证通过后，把原仓库收敛为治理与迁移控制面。

## Out of scope

- 产品功能重写、UI 重构、依赖升级和账号权限重设计。
- 删除 `bhrumom/fabushi`、已发布 Release、immutable tag、历史分支或既有 Userscript 仓库。
- 把 token、cookie、签名证书、provisioning profile、`.env` 或测试账户状态复制到新仓库。
- 在本机执行应用构建、原生测试、E2E、模拟器或打包。

## Deferred

- `fabushi/` 旧资产树的最终归属；本轮先审计并保留在源仓库。
- 是否将共享 Core 拆成多个独立 Rust crate 仓库；先以一个 Core 仓库完成边界稳定。
