# 路线图

| Stage | 目标 | 入口条件 | 退出条件 |
| --- | --- | --- | --- |
| M0 | 登记、基线和边界冻结 | canonical main 已读回 | PRS 项目记录、矩阵和 OSS 调研进入 PR |
| M1 | 创建目标 GitHub 仓库 | 命名/owner/visibility 已审阅 | 所有目标 repo 可读且保护规则存在 |
| M2 | 共享 Core、CLI 与平台边界化 | Core/API 版本策略已接受 | 构建脚本不依赖源仓库相对路径 |
| M3 | 历史/快照导出 | 源 SHA 与路径清单冻结 | 每个目标 repo 有可追溯 main/ref |
| M4 | 独立 CI/Release 验证 | 平台 workflow 迁移完成 | 每个平台/CLI packaged/E2E/Release 门通过 |
| M5 | 生产切换与治理-only 收敛 | M4 全部通过 | 源仓库不再承载平台产品源码，回滚锚点已归档 |
