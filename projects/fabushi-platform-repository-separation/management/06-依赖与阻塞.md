# 依赖与阻塞

## Dependencies

- `FAB-P0002`：项目 ID、项目文件和任务闭环。
- `FAB-P0003`：protected main、merge queue、Actions 和 Release 治理。
- `FAB-P0005`：Mahayana/Rust shared Core 的版本化边界。
- GitHub `bhrumom` owner 权限：创建仓库、配置保护、push 和 secrets。
- App Store Connect、Google Play、Chrome Web Store、Cloudflare 和生产部署权限：各平台切换。

## Blockers

- 当前没有阻塞 M0 的外部状态。
- 目标仓库的最终 Core package 版本、legacy `fabushi/` 资产归属和每个平台负责人需要在
  M2 前固定；在此之前不执行源仓库产品目录删除。
- 若 `gh repo create` 或跨仓库 push 权限不足，PRS 保持 `in-progress`，不以空仓库冒充迁移完成。
