# Owners and Review Responsibility

| Role | Owner | Responsibility |
| --- | --- | --- |
| Accountable owner | Repository maintainers | Approve the ref rewrite, protected-main exception and rollback decision |
| Execution owner | Active task agent/engineer | Maintain the isolated mirror, filters, audits and project records |
| Required reviewers | Repository maintainers | Review exact ref/path diff and verify protection restoration |
| Consulted stakeholders | Product owners of affected assets | Confirm that model, font, audio, scripture and submission assets remain available |
| Informed stakeholders | Fabushi contributors | Pull the rewritten repository only after the migration notice |

## Escalation

Escalate immediately if a protected rule cannot be restored, if a product path disappears, if the remote ref inventory changes during preparation, or if a credential/secrets concern is discovered. The escalation target is the repository maintainers.
