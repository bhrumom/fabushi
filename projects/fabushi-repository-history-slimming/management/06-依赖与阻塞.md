# 依赖与阻塞

## Dependencies

- `FAB-P0002`：项目文件标准、ID 注册和任务闭环。
- `FAB-P0003`：受保护主干、merge queue 和治理检查。
- GitHub 管理员会话：修改仓库规则的动作权限。
- 最新远端 refs：任何旧本地镜像都不能作为最终推送依据。

## Blockers

- GitHub immutable releases 锁定了 401 个已发布 tags；官方规则禁止在 release 存在时移动或删除 tag。为保留发布下载入口，本轮不删除 release，因此这些旧 OID 仍保持可达。
- GitHub server-managed `refs/pull/*` 不由普通 heads/tags push 改写；它们没有被伪造为已完成的迁移结果。
- 无未解决的任务阻塞。接受的瘦身产品 SHA `bc4fb3032a03d6600d733ce28295256d77cca9d4` 已由 [`Electron desktop quality gate`](https://github.com/bhrumom/fabushi/actions/runs/34085259212)（重跑成功）和 [`Native mobile quality gate`](https://github.com/bhrumom/fabushi/actions/runs/34085259258) 验证；当前 `main` 已继续前进到 `7ea5055b1e0d7ee078d0d21321b5884fa93bead2`。
