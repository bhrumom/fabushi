# RHS-REQ-001 — Repository history slimming

日期：2026-09-07

用户要求对 Fabushi 仓库进行彻底瘦身，先盘点占用空间最大的内容，再执行极致瘦身。用户明确允许修改仓库并要求继续执行。

## Normalized acceptance

- 清理历史中的构建产物、缓存、临时文件、备份文件和已确认的重复生成树。
- 保留产品源码、必要模型/字体/音频/经文数据、上架与软著材料及运行所需资源。
- 覆盖 GitHub 远端所有 heads 和 tags，并保存原始 refs 清单以便回滚。
- 推送前完成路径差异、对象完整性和 refs 数量审计；推送后立即复核。
- 临时调整保护规则只服务于这次迁移，完成后立即恢复原规则。
- 不在本机运行构建、打包、原生测试、E2E 或会产生大型产物的验证。
