# 架构与实现策略

迁移链路：远端 refs 快照 → 隔离 bare 镜像 → 只按审核路径过滤 → refs/path/对象审计 → 规则迁移窗口 → 原子 heads force push → GitHub 读回与完整性验证 → 立即恢复规则。Tags 绑定 immutable releases 时只审计并保留，不删除发布物；`refs/pull/*` 由 GitHub 管理，不伪造为可写 refs。

重写工具只运行在临时隔离目录，不改当前开发工作树。产品资产通过显式保留清单与 old/new tree 对照保护；生成规则通过 `.gitignore` 防回流。当前树删除了审核确认的生成/重复路径，运行时影响由 post-main GitHub Actions 质量门验证。
