# 质量与测试策略

## 轻量本地检查

允许：refs 清单、tree/path 对照、对象统计、`git fsck`、过滤结果搜索和配置审阅。禁止：应用构建、打包、原生工具链、模拟器、E2E 和可能生成大型树的测试。
