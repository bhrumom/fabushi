# 项目章程

## 问题

仓库历史包含长期累积的构建输出、缓存、临时目录和重复生成资源，增加 clone/fetch、Git 完整性检查和 CI 的磁盘与时间成本。

## 目标

在不损害产品源文件和必要发行材料的前提下，生成可验证、可回滚、覆盖全部远端 refs 的瘦身历史，并把防止回流的忽略规则纳入 canonical `main`。

## 约束与交付物

约束：历史重写会改变 commit/tree/blob OID；本机禁止构建和测试。交付物：项目记录、工具决策、过滤清单、refs 盘点、推送/恢复证据和迁移运行手册。

## 成功定义

所有验收矩阵项目通过，远端规则恢复，且 canonical `main` 读回结果与本项目记录一致。
