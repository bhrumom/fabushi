# 发布、迁移与回滚

迁移前公告受影响的 commit/branch/tag OID 变化，保存远端 refs 和保护规则快照。迁移窗口内只允许执行已审核的 heads 更新。GitHub immutable releases 锁定 401 个 tags，因此它们保持原 OID；`refs/pull/*` 由 GitHub 管理，也保持在平台控制范围内。成功后要求重新读回审计并恢复保护；失败时停止后续更新，按原始 refs 清单恢复受影响 heads，并保留失败证据。

本项目不是应用版本发布，不创建产品 Release，不改变 app version。回滚目标是使用 `/Users/gloriachan/Documents/fabushi-rhs-archive-20260907/remote-source-before-rewrite.git` 和 refs 快照恢复受影响 heads；immutable release tags 不做删除/重建。回滚操作同样必须在独立隔离镜像中执行。
