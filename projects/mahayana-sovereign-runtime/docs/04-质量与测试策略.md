# 04 质量与测试策略

Required layers:
- Rust unit/state-machine tests for kernel, supervisor, workspace, orchestrator, model/MCP/agent boundaries.
- Contract tests for command/event ABI and capability negotiation.
- Conformance tests comparing required Codex/Grok-derived semantics against Mahayana behavior.
- Source-boundary/provenance CI gate.
- Electron/native host E2E where surface behavior changes.
- Security tests for approvals, secrets, sandbox/network/process capabilities and recovery.
- Performance budgets for prompt queue, checkpoint/rewind, graph lookup and long-running supervision when implemented.

Heavy tests/builds are GitHub Actions only. A feature is not `passed` because code exists; evidence must name the commit, PR and required check/run.
