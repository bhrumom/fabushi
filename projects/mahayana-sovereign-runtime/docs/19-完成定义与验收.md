# 19 完成定义与验收

Project complete only when all required items below have objective evidence:
1. Capability matrix covers agreed Codex + Grok Build capability surface at pinned revisions.
2. Mahayana-native public contracts cover kernel/session/workspace/tool/memory/workflow/extension/model/policy.
3. Declared native crates pass source-boundary checks with no direct vendor product types/dependencies.
4. Remaining vendor implementations are optional adapters with provenance, or removed.
5. Codex and Grok-derived required semantics pass conformance tests.
6. Electron, iOS, Android, Web/CLI paths affected by migration pass their required CI/E2E gates.
7. Auth/secrets, approvals, sandbox, MCP and recovery security checks pass.
8. Release/migration/rollback docs and runbooks are current.
9. Protected-main merge and post-merge canonical verification are recorded.

Implementation complete is distinct from migration complete and project complete.
