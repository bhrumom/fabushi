# 06 PR / 分支规则

1. 项目治理分支：`project/grok-bot-fabushi-integration`；运行时实施使用任务化短分支。
2. 禁止把 `grok-bot-latest-source-fusion` 或 `grok-bot-0.16-source-fusion` 直接 merge 到 main。
3. 每个运行时 PR 绑定一个或少量紧耦合 GBF task ID。
4. PR 必须列 source/main diff、目标模块、权限影响、测试、rollback 与 provenance。
5. required `CI result` 通过后才可进入受保护 main/merge queue。
6. 高风险 computer-control/shell/credential/payment 类变更不得用“文档已审查”替代运行时测试。
7. 合并后必须回写 evidence、WBS、验收矩阵与状态报告。
