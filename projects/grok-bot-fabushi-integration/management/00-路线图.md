# 00 路线图

## M0 治理基线
建立项目文件夹、来源、需求、架构、安全、测试、发布、WBS、验收、ADR 和 evidence。

## M1 全量源码/能力盘点
递归清点 `grok-bot-latest-source-fusion`、`grok-bot-0.16-source-fusion` 与 `main`，完成文件级差异和功能级分类。

2026-08-24 扩展输入：固定并递归清点用户指定的 `bhrum/grok-bot-0.18-reconstructed`，其无明确源码许可的路径只作为 clean-room 行为/API 规格。

## M2 Electron 与 Host 收敛
逐项处理 main/preload/IPC/host/native handlers/native edge/ASR，保留 main 后续演进并迁移来源独有能力。

## M3 Agent/Coordinator/Local Exec 收敛
将调度、tool dispatch、MCP、session/resume、local exec 统一到 Mahayana sovereign runtime。

在单一 runtime 内增加 provider Router；provider 选择不得创建第二套 coordinator/tool policy/transcript。

## M4 电脑控制
建立跨平台 capability contract、敏感输入、浏览器/桌面控制与自动化 E2E。

增加 loopback-only、owner-bound 的本地容器执行环境和生命周期安全契约。

## M5 UI 与动画引擎
完成 Fabushi UI 集成、动态头像状态机和性能/无障碍优化。

增加 Router 设置、provider readiness、usage/billing 与本地执行环境控制面。

## M6 可靠性与可观测
数据迁移、恢复、崩溃、重试、结构化日志、指标与诊断。

## M7 安全与来源合规
威胁模型、权限拒绝测试、provenance/许可证 ledger 清零阻塞。

## M8 发布与归档
全平台回归、灰度、正式发布、历史 Grok 分支归档/保留决策。
