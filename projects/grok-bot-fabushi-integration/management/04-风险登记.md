# 04 风险登记

| ID | Risk | Severity | Mitigation |
|---|---|---:|---|
| R1 | 历史 Grok 分支落后 main，整合时覆盖后续修复 | Critical | 禁止 wholesale merge；能力级 diff |
| R2 | 来源/许可证不清导致发布合规风险 | Critical | provenance ledger；不清晰则重写/阻塞 |
| R3 | 形成两套 Agent/Host runtime | High | ADR-0001/0003；单一正式归属 |
| R4 | Electron IPC 过宽导致系统权限升级 | Critical | preload allowlist + capability gate |
| R5 | 电脑控制误操作/重放/目标漂移 | Critical | target-bound grants, expiry, revoke, E2E |
| R6 | 敏感输入泄漏 | Critical | 一次性通道、禁日志、过期与拒绝测试 |
| R7 | 动画引擎高 CPU/GPU 占用 | Medium | frame metrics、offscreen pause、reduced motion |
| R8 | 旧 Flutter/Tauri 架构回流 | High | main architecture gate；路径审计 |
| R9 | “源码存在”被误报为功能完成 | High | 状态模型 + objective evidence gate |
| R10 | 大爆炸迁移难回滚 | High | 原子 PR、feature/capability gate、rollback |
