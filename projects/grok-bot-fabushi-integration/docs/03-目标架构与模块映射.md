# 03 目标架构与模块映射

Grok 来源概念 -> Fabushi 正式归属：renderer -> `desktop/src`; Electron lifecycle/IPC -> `desktop/electron`; host/local exec -> capability host; coordinator/supervisor/agent loop -> Mahayana sovereign kernel; tools -> Mahayana tool/MCP/extension contracts; computer control -> platform capability adapters; animated presence -> renderer animation engine。

迁移优先级：先消除重复运行时，再迁移来源独有能力，最后删除/归档 compatibility code。
