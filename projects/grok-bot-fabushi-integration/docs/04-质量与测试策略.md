# 04 质量与测试策略

## Test pyramid / gates

- Unit：纯状态机、policy、数据转换、动画状态、错误分类。
- Contract：preload/IPC/capability/tool schema 的允许/拒绝/版本兼容。
- Integration：Electron main <-> host、Mahayana <-> tool/MCP、session/recovery。
- E2E：Electron/Playwright 真实用户路径；电脑控制授权/拒绝/撤销/过期/恢复。
- Security：command/path injection、replay、confused deputy、secret leakage、UI spoofing 等。
- Performance：启动、Agent first event、tool round trip、host crash/restart、CPU/RAM、动画 frame time。

## Test data / environment

测试凭证必须为假数据或 CI secret binding，禁止把真实密码/token/OTP 写入 fixture/log/evidence。平台特有能力在对应 OS runner/验证环境执行；不可用平台必须明确标记 blocker，不能以另一平台结果替代。

## Required CI

每个 PR 至少要求仓库聚合 `CI result`；触及 Electron/Mahayana/native 时运行对应变更域检查。高风险能力不能因 docs-only fast path 而跳过运行时验收。

## Flaky policy

失败必须先分类为产品缺陷、环境故障或 flaky；只有可复现证据支持时才能临时隔离 flaky，且必须创建跟踪任务。不得通过重复 rerun 把不稳定测试当作通过。

## Evidence retention

证据索引放 `evidence/<task-id>/README.md`，保存 PR、commit、run/job/check、报告/Release 引用，不提交大型构件或秘密。
# Router quality extension

Provider Router changes require backwards-compatible Rust serialization tests, Electron Host spawn/environment and fail-closed tests, native readiness/secret-redaction tests, and packaged Playwright assertions for provider selection/status, usage and sandbox rows. The canonical-main visual run must add a Router checkpoint while retaining the complete video, trace, HTML report and logs on an `always()` path.

No application build or test runs locally; all compilation and runtime verification uses GitHub Actions.

## GBF-411 quality gates

Required verification includes shared tool-schema tests, desktop loopback/auth/size/concurrency/cleanup tests, package file/tool handshake, renderer stale-generation and sensitive-input denial, Electron Playwright through the real bridge, Android unit + Compose semantic navigation, iOS unit/native tests, dynamic Runner catalogue verification, and regression of every existing `computer_*`, secure-input, remote OAuth/account-isolation and MiniApp WebMCP contract. Application builds, native tests and packaged E2E run only in GitHub Actions.
