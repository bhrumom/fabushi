# 15 完成定义

“Grok Bot 所有功能所有源码已融合”只在以下全部成立时可声明：

1. 来源分支与已知 Grok 输入 100% 文件/能力完成分类。
2. 所有保留能力均有 Fabushi 正式模块归属，不存在第二套长期 runtime。
3. 每个保留能力状态至少 `E2E_VERIFIED`；计划发布能力为 `RELEASED`。
4. 关键安全拒绝路径、崩溃恢复、权限撤销通过测试。
5. 来源/许可证 ledger 无未处理阻塞。
6. main CI 通过，并有真实 commit/PR/run/release 证据。
7. 历史融合分支完成归档/保留决策，不再作为产品运行权威。

在此之前只能报告真实阶段进度，不能把“源码已放进分支”视为完成。
