# 07 安全、隐私与合规

## Trust boundaries

Renderer 为低信任层；系统能力只经版本化 preload contract 与 main/host capability gate。shell、文件、浏览器、屏幕、键鼠、麦克风、摄像头、剪贴板、凭证/敏感输入均是显式能力。

## Authorization

默认 deny。grant 必须绑定 capability、目标、scope、请求/会话和到期时间；支持 revoke；过期/拒绝不可重放。敏感输入使用一次性目标绑定通道，严禁通过普通聊天/日志回传秘密。

## Threats

重点覆盖 privilege escalation、prompt injection、confused deputy、replay、UI spoofing、path traversal、command injection、target drift、secret leakage、supply-chain/provenance 风险。

## Privacy

computer control、截图、文件读取只在授权范围内运行；遥测记录必要能力/结果/错误，不持久化不必要的屏幕、文件或敏感内容。

## Provenance / license

每类外部来源记录来源位置、获得方式、许可证/授权、原样复用/重写/替代决策和 NOTICE 义务。许可不明确进入 `PROVENANCE_BLOCKED`，不能改名后当作 Fabushi 原创发布。

## Security review gate

computer-control、local-exec/shell、credentials/sensitive-input、payment/account side effects 等任务在 `RELEASED` 前必须有安全审查和对应 denial/replay/recovery 自动化证据。

## Provider Router controls

- Provider readiness returns booleans and source labels only; auth JSON and encrypted API-key values never cross the native boundary.
- OpenRouter and Claude API credentials use the OS-backed encrypted vault, never appear in readiness responses, and are injected only into the selected Host child generation.
- Inherited `ANTHROPIC_API_KEY`, `OPENROUTER_API_KEY` and generic model-bearer variables are scrubbed before scoped Provider environment values are applied.
- Corrupt/unreadable encrypted entries fail closed without crashing the Host lifecycle. The UI never echoes stored keys.
- Codex is opt-in, uses the user's existing Codex home, and remains inside the existing Mahayana Host approval, sandbox, MCP and transcript boundary.
- Codex auth discovery rejects symlinks, non-files, oversized JSON and unsafe POSIX permissions; it recognizes credential fields without returning their values.
- Local Docker remains below the same process approval gate and uses network-none, read-only root, dropped capabilities, no-new-privileges, PID/memory/CPU limits, tmpfs and a digest-pinned image. Only the active workspace is mounted read/write.
- Provider-neutral transcript/session files contain conversation content and are private local runtime state. POSIX creation uses mode `0600`; Windows inherits the private application-data ACL. They are not telemetry and must not be uploaded.

## GBF-411 App MCP boundary

App MCP publishes only bounded semantic state and allowlisted actions. Password, token, secret, cookie, OTP and payment credential values are never returned; direct semantic writes to sensitive fields fail closed and continue through encrypted secure input. Electron discovery is private and process-bound, transport is loopback only, requests/results/concurrency/timeouts are bounded, renderer responses are accepted only from the primary trusted window, and shutdown removes owned discovery. Device traces redact typed values. No arbitrary JavaScript, shell, reflection, database or internal-function tool is permitted.
