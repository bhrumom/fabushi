# Quality and Test

每个能力至少经过：静态检查 -> 单元测试 -> 模块集成测试 -> 风险相关 E2E -> PR `CI result`。

## 高风险能力额外要求

电脑控制、本机进程、文件系统、浏览器自动化、凭证/敏感输入、支付或账号操作必须覆盖：允许、拒绝、撤销、超时、重试、重复请求、崩溃恢复、权限升级拒绝。

## 迁移对照测试

对来源分支独有能力建立行为清单；若重构实现，测试验证行为目标而不是字节级复制。

## 完成规则

没有客观测试证据的任务最多只能到 `IMPLEMENTED`，不能标记 `TESTED`、`E2E_VERIFIED` 或 `RELEASED`。
