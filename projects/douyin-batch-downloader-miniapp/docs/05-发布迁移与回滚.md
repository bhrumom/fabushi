# 发布迁移与回滚

Rollout: PR -> protected `main` -> canonical package/E2E -> immutable market package -> versioned GitHub Release -> production marketplace search/install verification. Roll back by yanking the marketplace release and restoring the previous catalog/package commit; downloaded user media is never deleted automatically. Trigger rollback on credential exposure, wrong-content download, package digest mismatch, install failure, or required E2E failure.
