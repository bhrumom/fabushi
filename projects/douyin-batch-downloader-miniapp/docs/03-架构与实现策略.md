# 架构与实现策略

Flow: authenticated Douyin message UI -> user-authorized share URLs -> local MiniApp CLI/MCP -> short-link normalization -> embedded page-state/API parser -> non-watermarked playback candidate selection -> bounded sequential downloader -> local MP4 + `manifest.json`. The marketplace uses the existing Fabushi manifest/catalog/package/install protocol and immutable SHA-bound artifacts. Browser cookies remain in the browser; the runtime may accept an explicit session cookie file only when the user supplies it outside Git. Remote services never receive cookies. See `decisions/ADR-0001-local-first-douyin-resolution.md`.
