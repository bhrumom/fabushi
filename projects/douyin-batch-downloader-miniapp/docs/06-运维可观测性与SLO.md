# 运维可观测性与 SLO

SLI: successful resolutions/downloads divided by requested authorized URLs, excluding confirmed unavailable/private/CAPTCHA-blocked items. Target: deterministic CI 100%; marketplace browse/install 99.9% monthly; live parser smoke at least one successful public fixture per release. Logs are local and redact Cookie/authorization query data. Alerts are GitHub workflow failures and marketplace health checks. Runbooks: `runbooks/README.md`.
