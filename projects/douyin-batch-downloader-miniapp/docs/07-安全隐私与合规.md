# 安全、隐私与合规

Message contents and contact identity are confidential intake; video files remain local. Never commit cookies, tokens, message exports, or downloaded media. Restrict input hosts to `douyin.com` subdomains and media redirects to HTTPS; reject localhost/private-network redirection to prevent SSRF. Bound size/count/time, sanitize filenames, prevent path traversal, and write via temporary files plus atomic rename. Do not bypass CAPTCHA/access controls/DRM. Display a lawful-use notice and require users to confirm they have the right to download the selected content. Open-source ideas are reimplemented at Fabushi boundaries; no incompatible copied code.
