# Android 1.2.46 — full-home new-conversation semantic action unavailable

- Release: `android-v1.2.46-262491008`
- Release source: `c1533dadc47eca5cfe99ff6ff047d8f1d2e1fb8f`
- Interactive run: `34026819804`
- Fresh App-owned device: `gha-34026819804-1-interactive`
- Device kind: `github-actions-android-app`; no KRIS, historical device, macOS device, or runner-owned gateway was selected.

The released App registered itself after install/login. External control exercised `fabushi.app.status`, `snapshot`, `find`, `action`, `wait`, and `assert`: it entered the authenticated Grok shell, invoked `grok-mobile-legacy`, then verified full Fabushi `screen=home`. Snapshot generation 5 exposed `home-add-button` as an enabled button. `find` returned that exact element, but current-generation `invoke` returned `app_surface_action_unavailable`. A same-surface invoke on `home-search-button` succeeded, isolating the defect to New conversation rather than the full-home semantic bridge.

Exact source inspection found `FabushiScreen` publishes `element(TestTags.AddButton, "button", "...")` without an action, while the real `ConversationHome` FAB owns child-local `showComposeMenu` and sets it directly. The App-owned publisher therefore cannot trigger the real compose menu. The atomic correction hoists only `showComposeMenu` to `FabushiScreen`, binds `home-add-button` to the existing `invoke` contract, and passes the same state/callback into `ConversationHome`. This mirrors the repository's already-merged full-home search state-hoisting pattern. Official AndroidX Compose semantics source was also reviewed as the open-source-first reference for representing click behavior as a semantic action; no upstream code or new dependency is copied.

The 1.2.46 run is intentionally not force-logged-out after this deterministic functional failure. Its existing matrix timeout and always-upload path must retain full video, step screenshots, gateway trace, logcat, instrumentation/report diagnostics, and the failure state. Retest requires a protected merge, a strictly newer Android release from then-current canonical main, and a new run-bound App-owned Android device.
