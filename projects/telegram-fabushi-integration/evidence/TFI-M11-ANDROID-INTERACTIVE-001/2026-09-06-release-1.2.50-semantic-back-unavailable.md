MainActivity already implements `BackHandler(enabled = showLegacyShell) { showLegacyShell = false }`. However, `FabushiScreen` publishes `app-shell` without an action binding. On full-home generation 32, `fabushi.app.action` with target `app-shell`, action `pressKey`, value `BACK` returned exact error `app_surface_action_unavailable`. The atomic fix passes the existing `showLegacyShell = false` transition into `FabushiScreen` and binds only `app-shell` `pressKey BACK` to it. Unsupported keys are rejected. No arbitrary key injection, shell, reflection, JavaScript, authentication, gateway transport, messaging behavior, or visual navigation is added.
