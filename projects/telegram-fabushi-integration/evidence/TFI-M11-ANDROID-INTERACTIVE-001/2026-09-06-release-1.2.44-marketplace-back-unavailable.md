# Android 1.2.44 — marketplace App-owned back action unavailable

- Release: `android-v1.2.44-262490900`
- Release source: `c21942daa26c0a5dd143f9f24bf180f506895cc5`
- Interactive run: `34023749387`
- Fresh App-owned device: `gha-34023749387-1-interactive`

The run used only the fresh Android App-owned device and all six `fabushi.app.*` tools. The 1.2.42 authenticated-surface fix and PR #2422 full-home search fix were both verified on the released package. From full Fabushi home, the profile menu opened `插件市场`; marketplace search and Rust Host status were available.

Once `screen=marketplace` was entered, the App-owned snapshot exposed search, host status, and plugin controls but no back/close element. `fabushi.app.find` for `返回` returned no matches. Exact release-source inspection confirms the real Compose `MarketplaceContent` already has `OutlinedButton(onClick = onBack) { Text("返回消息") }`, while the `MobileDestination.MARKETPLACE` semantic publisher omitted that existing control entirely. The remote-computer destination already publishes an equivalent close action.

Atomic correction: assign the existing visual marketplace back button a stable `marketplace-back` test tag and publish the same control with semantic `invoke` routing to `HOME`. No marketplace behavior, plugin behavior, authentication, messaging, release, or gateway logic changes.

The 1.2.44 run is intentionally left on its normal failure/always-upload path so video, step screenshots, device trace, logcat and report are preserved. Retest requires a strictly newer Android release and a fresh run-bound App-owned device.
