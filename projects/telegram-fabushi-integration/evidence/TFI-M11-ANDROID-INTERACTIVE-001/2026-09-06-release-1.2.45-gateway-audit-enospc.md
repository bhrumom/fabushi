# Android 1.2.45 — remote MCP async-audit ENOSPC restart loop

- Release: `android-v1.2.45-262490926`
- Release/source SHA: `48bbcbbb2094e296e2fda0ed829bee68af1a12fa`
- Interactive run: `34025013929`, attempt 1
- Runner-reported device id: `gha-34025013929-1-interactive`
- Always-upload artifact: `9987002101`

The released APK, release JSON/checksum, installation, protected test-account authentication, no-refresh-token session import, and cold MainActivity launch all succeeded in GitHub Actions. The device was never stable in external `fabushi test` discovery.

The uploaded `device-gateway-trace.jsonl` proves the App repeatedly sent registration and received a `registered` acknowledgement, immediately followed by `transport_error:EOFException` (and occasional `ProtocolException`), then reconnects. The report ended `failed-timeout`.

During attempt 2, public `https://fabushi-mcp.ombhrum.com/health` returned HTTP 502 at the registration window. The origin host `bhrum2` remained online but its root filesystem reported `45G/45G, 0 available, 100%`, while the Node PID changed from `2602127` to `2605024` without host or cloudflared restart, proving an origin Node restart loop.

Source inspection identifies the crash edge: `createFabushiRemoteMcpServer` supplies an `async audit(record)` whose `appendFile(auditPath, ...)` rejects on ENOSPC, while `device-gateway.js` only catches synchronous exceptions around `options.audit?.(...)`. The rejected Promise can therefore escape after the server has already sent `registered`, matching the observed `registered -> EOF -> systemd restart` sequence. This violates the existing invariant that auditing must never break the control channel.

Atomic correction: consume asynchronous audit rejections inside the device-gateway audit wrapper, while continuing to catch synchronous throws. Add a regression test that injects an async audit rejection and requires the registered WebSocket/device to remain online. This does not waive the separate operational requirement to reclaim disk space and restore durable audit persistence on the production origin.
