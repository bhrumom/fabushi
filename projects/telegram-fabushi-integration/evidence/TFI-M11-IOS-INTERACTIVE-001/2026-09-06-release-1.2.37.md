Only the protected-main merge of this version candidate may be used for the next comparable iOS test publication. The `iOS interactive app device E2E` workflow must build and run only in GitHub Actions, start native recording before install, upload the exact Simulator test build before interaction, install it, authenticate the protected test account after installation, and let the installed iOS App self-register the new account-scoped gateway.
