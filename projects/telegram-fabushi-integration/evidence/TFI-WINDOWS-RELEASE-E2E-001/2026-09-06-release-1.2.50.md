## Why 1.2.50

Windows `1.2.48` exact-main Electron job `34027494210 / 101470965448` succeeded and produced the tested Windows installer, but same-SHA Native iOS `34027494208 / 101470965413` failed the remote-computer close Accessibility projection, so post-main could not publish it.

PR `#2434` atomically corrected that defect and protected-merged as `a2c25b12f64e3e8076bd456f90bd5d49a1677154`. A Windows `1.2.49` release PR was then prepared, but before it could merge, concurrent protected Android PR `#2436` advanced canonical `main` to global version `1.2.49` as `496d9f0910b1fced2eb594eded5310d5b8e5612c`. The existing Windows release PR was dequeued, updated with that exact latest main, and advanced again rather than colliding with the already-used global version. Therefore the next governed Windows candidate is strictly `1.2.50`.
