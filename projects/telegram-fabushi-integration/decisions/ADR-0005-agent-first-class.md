# ADR-0005 — AI Agent 一等公民

- **状态**：Accepted
- **日期**：2026-08-22
- **来源**：`../source/完整telegram融合进fabushi.txt`

## Context

这是 Fabushi 相对传统 IM 的核心产品方向。

## Decision

Agent 不作为外挂聊天页，而作为通信网络一等参与者，通过同一消息内核、群组 @、工具事件和 Agent-to-Agent 消息工作。

## Consequences

必须额外建设权限、审计、敏感工具授权和上下文隔离。

## Supersedes / Superseded by

无。
