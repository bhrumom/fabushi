# ChatGPT 自动确认 — 绑定会话优先恢复要求（2026-09-17）

## 原始要求

当 ChatGPT 自动确认油猴脚本出现“原消息发送结果超过 90 秒仍无法确认；当前页面链接未被绑定到本任务”的情况时，不应直接停止任务。

用户进一步明确：遇到这种情况应优先跳转到该任务已经绑定的真实会话链接，检查该绑定会话是否已经结束、是否已经出现最终回复；如果会话已经结束，就依据结束状态和最终回复判断下一步流程并继续执行。只有当前轮始终没有可用绑定会话链接、刷新后仍无法建立会话身份时，才进入周期恢复；周期为每 3 分钟一次。持续无法恢复时再新开会话并原样重发。

## 执行解释

1. 本轮 `task.url` 存在有效 ChatGPT `/c/...` 会话 URL 时，它是最高优先级恢复目标。
2. 90 秒发送确认超时后直接回到该 URL，检查最终回复、会话异常结束、授权、限流和既有阶段状态；已有最终回复则走现有 `finish` / work-review-next 流程，不重复发送。
3. 已绑定会话的停滞恢复继续沿用现有每 180 秒刷新同一 URL、可无限继续的语义。
4. 当前轮没有任何可用绑定 URL 时，保留派发 token 和已尝试标识，每 180 秒刷新当前页面并重新判断一次。
5. 无绑定 URL 连续 4 个恢复周期仍无法建立会话身份时，才清理旧派发身份，新开 Work/规划会话并原样重发。
6. 修改完成后递增 userscript 版本，发布公开 source Release，并同步 Fabushi parent bundled userscript / Marketplace 固定信息和项目证据。
7. 不用旧会话、旧 SHA 或自动 E2E 冒充正式发布验收；parent 正式稳定发布仍遵守根 `AGENTS.md` 的 exact-candidate + Fabushi official MCP 门禁。
