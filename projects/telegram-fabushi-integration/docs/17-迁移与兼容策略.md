## 旧栈删除策略

M0 代码审计前不能凭文档猜测实际旧目录名称。审计后必须建立“保留/重构/删除”清单，并满足：

- 一个能力只有一个正式 owner/module；
- feature flag 必须有删除日期/删除任务；
- 新栈通过验收后禁止新代码继续进入旧栈；
- 删除时检查 build files、CI、依赖、测试夹具、文档和运行配置；
- 无 GitHub/CI 证据不得声称旧栈已退出。
