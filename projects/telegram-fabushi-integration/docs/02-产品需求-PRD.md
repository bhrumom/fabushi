## 产品定义

Fabushi 的通信能力不是独立外挂 IM，而是 Fabushi 平台基础设施。真人联系人、Bot、AI Agent、Mini App 和支付围绕统一会话与消息总线工作。

## 核心用户场景

1. 用户与用户进行私聊、群聊、频道订阅与 Topic 讨论。
2. 用户把 AI Agent 当作一等联系人直接聊天，或在群组中 @Agent。
3. Agent 与 Agent 在权限隔离下通过统一消息网络协作。
4. 会话中启动 Mini App，并基于签名上下文、安全权限与支付 bridge 完成任务。
5. 桌面和移动端共享消息历史、草稿、已读状态、媒体和同步游标。
6. 网络中断后本地可读，恢复后增量同步，不丢消息、不重复。
