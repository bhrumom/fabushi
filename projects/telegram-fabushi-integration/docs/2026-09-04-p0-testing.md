Electron uses Playwright video/screenshots/trace/HTML results; Android uses emulator recording/screenshots/instrumentation/logcat; iOS uses Simulator recording/screenshots/`.xcresult`/debug evidence where applicable.

Passing and failing runs must upload evidence through an `always()`-equivalent path. Target retention is 90 days where GitHub policy permits; if the platform/repository policy permits less, use the maximum permitted and record that limit in the task evidence. A green assertion with any required evidence field missing is evidentially incomplete and **cannot pass**. Source-only tests or an unpackaged dev app cannot satisfy the packaged gate.

No local build/test/E2E is allowed; GitHub Actions is the heavy-verification source.
