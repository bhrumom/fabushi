## 身份/设备/联系人

账号系统必须完全使用 Fabushi Identity。

功能：
- 注册/登录
- 邮箱/手机号/Passkey/OAuth 等身份入口按现有 Fabushi 登录体系融合
- 用户名
- 昵称
- 头像/动态头像
- 简介
- 二维码
- 设备列表
- 登录会话管理
- 远程退出设备
- 新设备确认
- 联系人添加/删除
- 联系人备注
- 联系人分组
- 黑名单
- 隐私设置
- 最后上线时间权限
- 手机号/邮箱可见权限
- 群邀请权限
- 通话权限

统一联系人：
联系人页面同时显示：
- 真人联系人
- AI Agent
- Bot
- 工作空间成员

UI 上可区分身份类型，但底层使用统一 Participant 模型。
