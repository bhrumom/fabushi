## ChatGPT userscript closed-tab recovery（2026-09-11）

- Unit/DOM regression must cover in-place adoption by an empty replacement tab, retention of terminal-state history, rejection while the old tab's Web Lock is alive, and the dedicated-tab fallback for non-empty callers.
- Source delivery requires syntax + regression CI on the PR head and the exact accepted userscript `main` SHA.
- Live acceptance must use the published version and retain step-labelled screenshots, a complete video, action diagnostics, Chrome/version, source SHA and timestamps for create → close → reopen → recover → open recorded conversation.
- The task remains incomplete if the browser still runs the prior version or if any required visual/diagnostic evidence is missing.

## ChatGPT userscript abnormal-end retry（2026-09-11）

- The short watchdog must be tested when supervision witnesses Stop disappearing and when its first observation is already clear.
- A changing assistant/tool-call surface resets the timer. Stop, authorization, valid final output, blocker, rate limit or ownership mismatch cancels it.
- Live evidence must prove the published version automatically abandons only the ended target, opens a fresh Chat, and resends the unchanged work/planner prompt without exceeding the four-attempt ceiling.
