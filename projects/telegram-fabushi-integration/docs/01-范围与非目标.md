## In Scope

- Fabushi 自有账号、设备、联系人、群组、频道、Topic、消息、同步、媒体、搜索、通知、Bot/Agent、Mini App、支付、实时音视频体系。
- Electron、iOS、Android 共享 Rust Core 与协议。
- 自建服务端和自主部署能力。
- Telegram Desktop/Unigram 同类成熟交互能力的功能级对标。
- 旧通信栈最终退出主路径。

## Out of Scope / 明确非目标

以下内容来自源计划的边界表达：
- 不把 Fabushi 做成 Telegram 第三方客户端。
- 不依赖 Telegram API、Bot API 或 MTProto 网络。
- 不复制 Telegram 商标、品牌资源、受限制专有资产或不兼容许可代码。
- “完整融合”是功能、交互范式与工程能力对标，而不是品牌/代码逐字复制。

## 范围变更规则

新增重大能力（例如 Stories、群组 SFU 通话）如果超出当前确定范围，应先形成 ADR/范围变更记录，再进入 WBS。
