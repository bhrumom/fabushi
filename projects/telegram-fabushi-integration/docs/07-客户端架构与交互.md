## Electron 桌面端

桌面端需要完整实现 Telegram 类成熟 IM 的操作密度，但采用 Fabushi 设计语言。

三栏基础布局：
- 左：导航 + 会话列表
- 中：当前会话
- 右：会话详情/成员/媒体/搜索

主导航：
- Chats
- Contacts
- Agents
- Calls
- Mini Apps
- Settings

会话列表：
- 头像
- 名称
- 最近消息
- 时间
- 未读数
- mention
- mute
- pin
- draft
- sending state

聊天区：
- 消息虚拟列表
- 无限历史加载
- 回复预览
- reaction
- 编辑态
- 选择态
- 文件拖入
- 图片粘贴
- emoji/sticker/GIF
- 语音录制
- @mention
- command
- Mini App button
- payment button

右侧详情：
- Profile
- Members
- Shared media
- Files
- Links
- Voice
- Permissions
- Notifications

快捷能力：
- 全局搜索
- 快捷键
- Command Palette
- tray
- badge
- native notification
- protocol/deep links
- drag and drop
- multi-window（后期）

性能要求：
- 10 万消息会话不因 DOM 数量卡顿
- 虚拟列表
- 图片懒加载
- 头像缓存
- 搜索异步索引
- IPC 不传大二进制，媒体走流/文件句柄

## iOS / Android

iOS：
- SwiftUI/UIKit + Rust core
- APNs
- CallKit
- PushKit（仅符合平台政策场景）
- StoreKit
- Share Extension
- Background tasks
- Keychain

Android：
- Kotlin/Compose + Rust core
- FCM
- Connection service
- Play Billing
- Share intent
- Keystore
- Foreground service（仅必要场景）

要求：
- 协议和消息状态机不在 Swift/Kotlin 重写。
- UI 平台原生化，但行为由共享 domain contracts 保证一致。
