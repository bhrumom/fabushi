# 项目章程

现有 Computer Control Bridge、Fabushi 产品桥和自动化脚本分属不同扩展身份，造成
权限、连接、账户和发布维护分裂。CWA 将它们合并为一个可审计的 Fabushi Chrome
平台，并让桌面 Host 保持密码、Cookie、refresh token 等长期凭据的唯一所有权。

利益相关者是使用现有 Chrome 标签页的用户、桌面/浏览器维护者、安全维护者和发布
维护者。约束包括 MV3/native messaging/Debugger 兼容、精确来源与权限说明、保护
分支和 CI 验证，以及本机不得执行大型应用构建或 E2E。

交付物是 0.6.0 扩展 ZIP、SHA-256/内容清单、桌面 native hosts、契约和安全测试、
Web Store 更新、真实迁移证据。成功定义是新 Fabushi 扩展独立完成旧 Bridge 全部
浏览器旅程，且旧扩展身份在原 Profile 中不存在。
