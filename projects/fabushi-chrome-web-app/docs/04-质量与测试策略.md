# 质量与测试策略

Static contract 检查 MV3 manifest、权限/host allow-list、白名单 ZIP、命令/动作/事件
parity、native host identity 和无远程 executable code。

Unit/contract 覆盖 chatgpt-vps-control 的 browser-extension、chrome-platform、
extension-entry、userscript tests，以及现有 browser-session、desktop Host/server
tests。Security 覆盖未认领/非 HTTP、标题 URL generation 陈旧、伪造 extension ID、
错误 secret/origin、敏感输入、远程脚本指令、跨账号、旧 host replay 和 debugger
策略禁止时的明确失败。

GitHub Actions 运行 Chrome focused workflow、项目治理、Electron 三平台和 canonical
post-main package/E2E。重型构建、native 测试、模拟器和打包 E2E 不在本机执行。
每个 canonical-main journey 都保留分步截图、完整视频、Playwright trace/HTML report
和平台日志，always 上传，目标保留 90 天并绑定 SHA/version/run/test ID。

CWA-007 覆盖发布 origin 拒绝、首帧认证、同 device ID 跨账号隔离、MCP 命令往返、
退出撤销、凭证失效、重连和浏览器事件有界读取。打包旅程使用官方 MCP 的
`list_devices`/`device_call` 证明同账号正向与异账号拒绝。

CWA-008 增加 `userscript-recovery.test.js` 的 lease/metadata/crash/close/URL 负向合同，
并由 `chatgpt-task-queue-userscript.test.js`、extension validator 和 packaging verifier
锁定 service worker import、content bridge、v2.9.20 bundle 与 allow-list。source userscript
回归覆盖最终回复→验收、附件重注入、唯一 URL 接管和 blocked 恢复确认窗口。canonical-main
必须运行打包 crash/error-page → reload/takeover → userscript workspace/attachment/final
handoff 旅程，并 always 保留 checkpoint screenshots、完整 video、trace、HTML/report 和
runtime logs；轻量本机结果不能替代 CI。
