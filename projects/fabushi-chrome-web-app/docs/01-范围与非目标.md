# 范围与非目标

## In scope
Fabushi Chrome 产品壳、Chats、Mini Apps、Marketplace、设置和账户复用；九个 Bridge
命令、八个动作、CDP/OOPIF、下载、创建/保留/释放/清理、detach、分组、子标签继承、
断线恢复和 generation fail-closed；0.4.1 用户脚本运行器、ChatGPT 自动确认工作台和
Task Queue 的安装/启停/卸载；双 native hosts、明确白名单、CI 包、Web Store 和迁移记录。

## Out of scope / deferred
不复制官方 ChatGPT 的书签、历史、侧栏或其他非 Bridge 功能；不删除共享 Computer
Use MCP、原生辅助功能、截图运行时或桌面账号存储；不执行远程 JavaScript，导入脚本
拒绝 @require、@resource、@connect、eval、动态 import、WebAssembly 和非 HTTP(S) 匹配；
旧 host/目录清理只能在发布和真实旅程通过后执行。
