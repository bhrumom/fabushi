# 需求与成功指标

1. Action opens a complete Fabushi UI with Chats, Mini Apps, Marketplace and search.
2. Loading, empty and status states are visible and accessible.
3. MV3 manifest and local resources are internally consistent.
4. Production ZIP can be built deterministically from the extension directory.
5. Store listing asset checklist, privacy/permission rationale and publish checklist are explicit.
6. Existing userscript implementation is not expanded.
