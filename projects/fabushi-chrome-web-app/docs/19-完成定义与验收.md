in-progress or blocked; local static checks alone are not completion.


## Grok Bot 0.18 Chrome parity gates

| Gate | Required evidence |
|---|---|
| Grok inventory | pinned `source/**` + `frontend/**` ledger 100% audit/disposition |
| Product responsibility | every relevant Grok responsibility production-wired or evidenced equivalent |
| Full Grok UI | full-page extension app screenshots/video for roster, conversation, transcript, composer, tools, MCP, settings/context |
| Runtime boundary | Renderer -> Platform Runtime -> Coordinator -> Host -> Runner architecture/contract evidence |
| Worker lifecycle | Service Worker restart mid-turn -> same run resync, no duplicate send/tool |
| App lifecycle | app reload/close/reopen mid-turn -> same durable run resync |
| Desktop optionality | desktop/native host offline while remote Coordinator still completes core Agent journey |
| Existing Browser Control | nine commands/eight actions + CDP/OOPIF/download/tab lifecycle regression |
| Existing userscripts | install/update/enable/disable/recovery regression |
| Existing Mini Apps/Marketplace | packaged UI/install/update regression |
| Existing account/MCP | login, same-account allow, cross-account deny, logout revoke |
| Grok Agent lifecycle | accepted/thinking/tool-running/streaming/cancel/retry/recovery/terminal trace |
| Security | no regression in origin, native-host, session, generation, CSP, userscript boundaries |
| Strict architecture | no hidden legacy primary shell, no renderer->Host/Runner bypass, no equal-file-count requirement |
| Grok Bot Chrome effect | real browser task invokes Browser Runner/MCP, shows live tool state, continues inference and streams final result |
| Exact-HEAD delivery | packaged ZIP/checksum/content manifest/E2E/Release/Web Store evidence |

Grok parity completion is **not** satisfied by preserving the existing extension alone. It requires
both: (1) zero regression across all approved existing CWA capabilities; and (2) complete
Grok-shaped Agent product/UI/runtime acceptance from the same exact source SHA.
