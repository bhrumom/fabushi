# 安全、隐私与合规

Tab title/URL、截图、DOM/CDP 结果和下载 metadata 是运行数据；密码、Cookie、refresh
token、auth header 和敏感输入属于 restricted，扩展不得持久化或返回。

com.fabushi.chrome_platform 仅负责产品/账户，服务器允许有限方法并阻止 secret.provide、
session.clear、update.install。com.fabushi.browser_control 仅负责浏览器/CDP，claim
要求当前 title、URL、generation；未认领、非 HTTP(S) 和陈旧 target 失败。native
manifest allow-list 稳定 Fabushi ID，per-user secret 防止随机连接。

用户脚本沿用 0.4.1 的逐脚本安装、启停和页面握手；内置脚本只匹配两个 HTTPS ChatGPT
域名，导入脚本拒绝非 HTTP(S) 页面和 @require/@resource/@connect、eval、动态 import
和 WebAssembly。脚本源随 Fabushi 包发布，CI 以白名单和 provenance 清单约束供应链，
不在运行时执行远程 JavaScript。仅官方 Chrome API 文档/示例用于架构参考。

Chrome 独立登录只持有短期 access token 和进行中的 poll secret，均在默认不向
content scripts 开放的 `storage.session`，不持久化 refresh token。`/browser-agent`
拒绝非稳定发布 extension origin，要求十秒内首帧认证，由服务器解析账号；客户端
不能声明 account id。事件限制数量和单项大小。退出或认证失效撤销 claims、debugger
与 generation，防止旧 MCP 会话继续操作。

CWA-008 的宿主恢复租约是 restricted metadata，字段限定为 owner/tab/task/state、phase/round、
规范化 ChatGPT URL、恢复票据、附件 ID 和时间戳；目标正文、完整 prompt、Cookie、access/
refresh token、DOM 内容、文件 Blob 和用户输入绝不进入扩展恢复存储。request 必须来自
关联的 ChatGPT tab，恢复 URL 拒绝外部 origin、query、任意脚本地址和不安全 scheme；lease
按 tab/owner 绑定并有 expiry/cooldown。暂停、取消、完成及 tabs.onRemoved 清除租约，防止
用户主动关闭的标签页被意外重开。负向测试覆盖 unsafe URL、未声明可恢复 blocked 状态、
租约冲突和内容字段不落盘。

### CWA-009 marketplace security boundary

GitHub 托管源码、Release 和安装包；Worker/D1 只保存经过校验的来源、版本、大小、SHA
和安全状态。候选版本默认 `pending/unlisted`，安全服务器完成恶意软件、密钥、依赖/SBOM、
动态探针和签名验签后才允许公开。公开版本复扫失败立即 `revoked`，阻断目录、下载、安装
和路由，并保留审计与回滚指针。

自有安全服务器是独立的 restricted trust zone：token、Cosign 私钥、公钥文件和密码只
通过服务器 secret store/受限文件提供，绝不进入 GitHub、插件包、扫描容器或日志。服务
逐跳限制 GitHub artifact 域名并校验摘要/大小；解包拒绝路径穿越、符号链接、硬链接、
设备文件、过量成员和压缩炸弹。ClamAV 在宿主只读扫描；Gitleaks、Syft 和动态探针使用
无网络、只读、无特权、有资源上限的容器；OSV 查询单独联网但不执行插件代码。

Docker 配置是防御纵深而非多租户 VM 保证。高风险或不可信运行时应迁移到专用
Firecracker/等价 micro-VM，并在启用更强沙箱前保持 fail closed。扫描结果只存状态、工具
版本、服务器实例/源码 SHA、包摘要和签名 bundle，不存密钥原文、命中片段、任务正文或
插件输出。
