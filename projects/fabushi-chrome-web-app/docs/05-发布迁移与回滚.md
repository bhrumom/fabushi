# 发布、迁移与回滚

合并保护 main 后，重新读取 exact merge SHA 的 registry/project metadata；运行 Chrome
package 和 Electron desktop packaged E2E；同一 SHA 发布严格递增的 GitHub Release 和
现有 Web Store 条目。ZIP、SHA-256、content manifest、签名安装包和 updater metadata
必须来自同一来源。

迁移时先停止控制并让旧 Bridge detach，保留用户/自动化标签，安装 CI 产物，重新枚举
并以新 generation 认领。真实旅程通过后，在 Default/Profile 2 的 chrome://extensions
界面删除旧 Bridge 与官方 ChatGPT；随后注销旧 native host 并只把旧 Bridge 专属目录
移入 Trash（CLI 的 cleanup-legacy 只在这一步之后运行）。不得编辑 Secure Preferences，
不删除共享 Computer Use runtime/native helpers。回滚使用上一份签名 Fabushi 包并保持
标签页不变。
