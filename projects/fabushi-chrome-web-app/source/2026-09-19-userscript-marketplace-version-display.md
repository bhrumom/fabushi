# 用户需求：修复脚本市场版本显示不一致

- 日期：2026-09-19（Asia/Shanghai）
- 归属：FAB-P0011 / CWA / CWA-012
- 来源：用户截图与最新对话要求

## 原始问题

Chrome 插件的 Marketplace 卡片显示 `2.9.37`，但同一张卡片的安装状态显示已安装
`2.9.39`。用户要求修复该不一致，并保持油猴式模型：Marketplace 负责首次发现/安装，
已安装脚本继续通过自身 `@updateURL` / `@downloadURL` 自动检查新版本，不需要每次脚本
发版都同步修改市场目录。

## 已确认事实

- `2.9.37` 来自 Chrome 插件内置的旧目录兼容基线；它不是已安装脚本的当前版本。
- `2.9.39` 来自脚本元数据并已由更新 URL 检查器写入安装记录。
- 更新器的版本比较已经以脚本元数据为权威；缺陷只在卡片元信息仍直接渲染目录版本。

## 本轮验收意图

- 已安装用户脚本的卡片版本显示安装记录中的脚本 `@version`。
- 未安装用户脚本仍显示市场目录的首次安装基线。
- 目录保持兼容回退用途，不能覆盖更新 URL 的版本检查，也不能触发降级。
