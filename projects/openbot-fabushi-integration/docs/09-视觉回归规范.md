Visual gate:

- Playwright `toHaveScreenshot` remains the authoritative visual-regression gate with per-pixel `threshold=0.15` by default and maximum differing-pixel ratio `0.08` (8%) unless an explicit stricter environment value is supplied.
- A second same-run audit report, `visual-diff-report.json`, records a deterministic channel-difference metric for the whole `1671x937` workspace plus app-controlled semantic regions. Its global ratio must also be `<= OBF_MAX_DIFF_PIXEL_RATIO`; it is an audit metric, not a replacement for Playwright's comparator.
- `geometry.json` records actual bounding boxes for navigation column, roster column, header, transcript, four coworker rows and avatar boxes, peer-row gaps, final assistant card, result table, source-file chips, real attachment card, hover operations, composer, and composer input. Roster BotMark boxes must stay within `34px +/-2px` in both dimensions.
- Semantic region residuals are reported for `column-navigation`, `column-roster`, `header`, `transcript`, `avatar-chief`, `avatar-research`, `avatar-builder`, `avatar-launch`, `final-message-card`, `table`, `source-files`, `attachment-card`, `hover-actions`, and `composer`. Every non-zero region is listed in `residualRegions` with differing pixels, total pixels, and ratio.
- Identity is exact rather than approximate: `identity.json` must prove the same canonical Chief Bot `data-shape` in roster, header, final assistant transcript, and after closing/relaunching the same packaged app-data directory.
- Lifecycle is runtime-derived: `lifecycle.json` must contain `thinking`, `running`, `completed`, and an intentionally induced/recovered `failed` tool status from the real Mahayana workbench path; the final assistant completion is sent through the ordinary composer and waits for the real agent run to reach `completed`.
- Any non-zero accepted visual difference must be reported by region and described as residual difference. Zero differing pixels is the only basis for wording such as literal “1:1”; `<=8%` is only the agreed acceptance threshold, not a claim of zero difference.
