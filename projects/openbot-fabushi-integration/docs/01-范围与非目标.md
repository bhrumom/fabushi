# 范围与非目标

In scope: reference UI/roster/avatar/channel/reply lifecycle/rich result/source files; upstream computer/browser/files/tools/live-screen/take-over/policy/audit capabilities; stable identity; packaged Desktop visual/runtime evidence.

Non-goals: embedding OpenBot runtime, replacing Mahayana, adding a second tool gateway/store/conversation model, copying OpenBot assets when Fabushi equivalents exist, or fabricating static transcript rows/screenshots to satisfy acceptance.
