# 架构与实现策略

Mahayana remains the sole executor and authoritative event source. Messenger remains the sole conversation projection. Existing BotMark, computer-control, RustDesk/live-control, ToolHost/policy/approval/audit, Mini App/component and file surfaces are reused.

Implementation rule: inventory first; only verified UI/rendering/evidence gaps receive local changes. Structured visual results must be a deterministic rendering of assistant/runtime content, never a hard-coded fake transcript. See ADR-0001.
