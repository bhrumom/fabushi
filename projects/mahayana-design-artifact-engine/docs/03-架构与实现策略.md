# 架构与实现策略

```text
Mahayana Kernel (only executor)
  -> Extension/Skill Resolver
      -> DesignPackage + Craft + Skill metadata
      -> project-private staged resources
  -> Agent run
      -> typed ArtifactManifest events/files
  -> existing Agent Workbench
      -> artifact card / preview router
      -> existing MiniApp/WebMCP host for interactive apps
      -> export capability registry
```

External CLIs remain adapters behind Mahayana. The reusable OpenDesign lesson is declarative adapter data and shared lifecycle logic; Mahayana owns the actual process/session/policy implementation.

Design packages use `manifest.json + DESIGN.md + tokens.css` as canonical minimum. Rich optional files include `USAGE.md`, component fixtures, token JSON, assets and previews.
