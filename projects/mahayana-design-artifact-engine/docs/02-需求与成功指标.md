# 需求与成功指标

- MDA-R1: one canonical Fabushi design package is machine-readable and agent-readable.
- MDA-R2: design skills can declare artifact mode, preview, design-system and craft requirements.
- MDA-R3: skill side files are staged into project-private isolated paths; source bundles are not mutated.
- MDA-R4: external runtime profiles are data declarations consumed by Mahayana, not a second loop.
- MDA-R5: artifacts carry typed manifest metadata sufficient for preview/export routing.
- MDA-R6: HTML/MiniApp preview is sandboxed through existing trusted host boundaries.
- MDA-R7: exporters are registered by capability and fail closed when unavailable.
- MDA-R8: MiniApp generation can hand off to existing marketplace/publish pipeline.

Success requires tests for each contract plus protected-main and post-main evidence for product-affecting changes.
