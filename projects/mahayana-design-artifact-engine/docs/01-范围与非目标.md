# 范围与非目标

## In scope
Design package schema; Fabushi default design package; design skill metadata; craft registry; staged skill resources; declarative external runtime profiles; typed artifact manifest; safe preview policy; export capability registry; MiniApp design/publish handoff; tests and provenance.

## Non-goals
Embedding OpenDesign desktop UI/daemon; replacing Mahayana kernel; copying OpenDesign cloud billing or brand assets; bypassing existing MiniApp permissions/WebMCP; claiming binary/visual parity with OpenDesign.
