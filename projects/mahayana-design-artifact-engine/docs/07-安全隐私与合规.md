# 安全隐私与合规

Reject unsafe relative paths, traversal, symlinks/hardlinks in imported/staged bundles; keep secrets out of manifests/prompts; keep external CLI permissions under Mahayana policy; sandbox HTML previews and route MiniApp capability access through existing WebMCP/Host policy; record Apache-2.0 provenance and third-party licenses. No cloud key or credential is added by this project.
