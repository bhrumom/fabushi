# 项目章程

Problem: Fabushi already has Mahayana execution and Agent Workbench, but lacks a first-class design-system/craft/artifact delivery layer that makes generated MiniApps, web artifacts, decks and documents consistent, previewable and exportable.

Objective: add those capabilities as Mahayana/Fabushi-owned contracts while preserving one executor, one permission system and one conversation/workbench projection.

Success: a Mahayana run can resolve a design package + design skill, stage resources safely, emit typed artifacts, preview them in the existing workbench/MiniApp host, and expose export intents without introducing a second runtime.
