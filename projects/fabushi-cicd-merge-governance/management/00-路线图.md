# 路线图

## G0 — Fast safe merge — completed

Change-aware PR/merge-group CI, unknown-path fail-safe, queue-aware automerge, and unrelated production-deploy gating. Evidence: PR #1978, #1984, #1985.

## G1 — CI latency budget — completed

`CI latency observability` now measures real recent `CI` runs by validation surface and publishes P50/P95 + queue delay + JSON/CSV artifacts. Acceptance run `32564046852` sampled 50 runs; fast-path P95=22s against a 30s budget.

## G2 — Release train / deployment promotion — completed

Apple and Google manual store delivery now validate exact source SHA against protected `main` plus required canonical platform gates before expensive build/sign/upload. Governance contract run `32564046827` passed.

## G3 — Policy automation — completed

Narrow `.github/CODEOWNERS` covers sensitive CI/CD/release/payment surfaces without a repository-wide catch-all; `Delivery governance contract` validates ownership/release/merge invariants.

## G4 — Incremental build & test efficiency — active

Goal: make GitHub-hosted Actions behave as close as safely possible to a warm incremental build across runs while separating PR feedback from post-main heavyweight validation.

### G4.1 PR fast lane

- PR/merge-group: static/type/format/contract/necessary unit checks only.
- No Playwright/desktop E2E, Android instrumentation, iOS UI E2E, installer packaging or Debug package production on PR.
- Required aggregate safety gate remains.

### G4.2 Post-main heavy lane

- Protected `main` push is the trigger for installer builds, Debug packages and E2E.
- Impact classifier selects only affected desktop/mobile platforms.
- Signing/release provenance remains separate from ephemeral caches.

### G4.3 Cross-run incremental cache

- Electron: npm dependency cache, renderer build cache where safe, native Host compiler cache and source-keyed reusable binaries.
- Rust: Cargo registry/git + target/compiler caches with toolchain/workspace keys.
- Android: Gradle dependency/build cache, source-keyed JNI libraries, SDK/AVD caches where safe.
- iOS: source-keyed Rust static library, Cargo cache, safe SwiftPM/DerivedData reuse keyed by Xcode/SDK/project inputs.
- Cache miss must cleanly rebuild.

### G4.4 Evidence and SLO

- Report hit/miss and cold/warm durations.
- Run at least one two-run warm-cache experiment per major platform family.
- Target >=50% wall-clock reduction for small-change warm builds versus cold baseline.

## G4 exit gate

FCM-009 tasks passed; protected PR/merge evidence recorded; canonical `main` re-read; PR fast lane and post-main heavy lane verified with real Actions runs; cache correctness and warm-build speed evidence recorded.
