## Scope

One implementation branch/PR carries controller, tests, CI and records. Reuse existing Mahayana production code, `mahayana.test-driver.v1`, app semantic operations and Playwright/Vite. Do not invent a second product runtime, duplicate business logic in UI fixtures, introduce local heavy builds, or expand to unrelated feature rewrites.

## Evidence contract

Each suite reports source SHA, layer, suite ID, execution command/cwd, exit status, monotonic duration, result classification and retained evidence path. UI evidence is not core acceptance; core evidence is not native/package acceptance. A passing selected lane does not imply all product features or all platforms passed. Missing required results and incomplete coverage remain explicit.

Use bounded automatic repair only with an authorized executor and frozen acceptance constraints. Preserve original failure, add a regression, rerun the affected layer, widen validation before protected integration, and keep platform release gates intact. Stop on repeated identical failure, missing credentials, unsafe operations, new semantics requiring architecture change, or exhausted budget.
