## Implementation

- `chatgpt-vps-control/lib/app-agent-ci-smoke.js`
  - waits for the existing App Agent surface;
  - validates semantic snapshot redaction;
  - opens/closes the profile menu using stable agent ids + generation-safe actions;
  - requires structured wait/assert success.
- `chatgpt-vps-control/scripts/run-app-agent-ci-smoke.mjs`
  - writes `fabushi.app-agent-ci-smoke.v1` JSON evidence without discovery token/session material.
- `chatgpt-vps-control/tests/app-agent-ci-smoke.test.js`
  - validates semantic-only operation sequence;
  - rejects failed assertions;
  - rejects sensitive values.
- `.github/workflows/macos-interactive-app-e2e.yml`
  - runs the Action-owned smoke after installed App registration and before the external full journey;
  - includes the smoke report in existing evidence;
  - fails the truthful evidence gate when the Action-owned smoke did not succeed.
- `.github/workflows/ci.yml`
  - runs the smoke unit tests and macOS workflow contract inside the lightweight required CI gate.

## Truthful completion boundary

Do not mark FCM-010.10 passed from static/PR tests alone. The implementation can merge once PR gates are green, but the task remains `in-progress` until a release-triggered canonical exact-source macOS packaged run executes the new smoke against a real installed Fabushi App and preserves the report in the evidence artifact.

The 1500-second external full-journey hold remains intentionally present. Removing or shrinking it is a follow-up only after an Action-owned full journey reaches evidence equivalence.
