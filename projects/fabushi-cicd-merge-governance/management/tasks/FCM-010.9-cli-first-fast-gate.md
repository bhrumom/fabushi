## Implementation

- `.github/workflows/mahayana-fast-checks.yml`
  - adds `cargo test -p mahayana-cli --profile ci --no-default-features` before broader compatibility suites;
  - adds `cargo test -p mahayana-test-driver-protocol --profile ci` immediately after the CLI gate;
  - preserves existing sparse checkout, `CARGO_INCREMENTAL=1`, `Swatinem/rust-cache@v2`, affected-path triggers and superseded-run cancellation.
- `chatgpt-vps-control/tests/mahayana-cli-fast-gate-contract.test.js`
  - locks the CLI/test-driver steps and their ordering;
  - locks the fast-path primitives and rejects accidental `cargo test --workspace` expansion.
- `.github/workflows/ci.yml`
  - runs the new contract under the existing 3-minute required CI job.

## Known remaining performance gap

The existing macOS packaged interactive workflow can still wait up to 1500 seconds for external `@fabushi test` completion after the installed App has registered its local semantic App Agent surface. `FCM-010.9` does not pretend that latency is solved. The next optimization should self-drive a deterministic packaged semantic smoke/full journey from the GitHub Actions host through the existing private loopback App Agent bridge, retaining remote MCP as an independent interactive/full-journey acceptance path until equivalence is proven.
