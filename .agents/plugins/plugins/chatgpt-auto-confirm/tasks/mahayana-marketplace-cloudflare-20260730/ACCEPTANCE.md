# 验收标准：大乘 CLI 云端插件市场

任务只有在以下条件全部满足后才能报告 `complete`：

1. 官方市场端点能够返回目标小程序及其有效版本元数据。
2. 目标小程序已真实部署到独立的 Cloudflare Pages 或 Workers 地址。
3. 插件包和所需静态资源未使用 R2 作为分发源。
4. 大乘 CLI 能浏览该小程序的市场信息和详情。
5. 大乘 CLI 能完成下载、来源及完整性校验、安全安装。
6. 已安装状态和版本状态可被再次查询并保持一致。
7. 大乘 CLI 能启动该小程序并取得真实运行结果。
8. 失败路径至少覆盖无效来源、校验失败或网络失败中的关键场景。
9. GitHub Actions、部署地址、市场响应和安装运行结果均有可复核证据。
10. 没有以 mock、仅本地夹具或仅接口单测替代真实端到端验证。

最终机器报告的 `verification` 必须列出相应 Actions run、部署地址、插件 ID/版本、安装结果和运行证据。
