# UI/UX：大乘 CLI 云端插件市场

## 市场浏览

- 清晰显示插件名称、版本、发布方、简介、兼容性和安装状态。
- 区分官方插件、已安装插件、可升级插件和不可用插件。
- 加载、空状态、网络失败和权限失败需要明确反馈。

## 插件详情

- 展示来源地址、版本信息、更新说明和必要权限。
- 安装前让用户理解插件用途、来源和可能影响。
- 不把内部存储地址或无效占位链接展示为正式下载入口。

## 安装与运行

- 安装过程显示当前阶段和最终结果。
- 重复点击安装不应创建重复安装或损坏状态。
- 安装成功后提供明确的打开或运行入口。
- 启动失败时保留可诊断错误，而不是无响应或静默退出。

## 一致性

- CLI 输出与图形界面状态使用同一插件 ID、版本和安装状态语义。
- 文案应说明真实操作结果，不能把仅下载成功表述为安装和运行成功。
