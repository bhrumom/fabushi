# PRD：大乘 CLI 云端插件市场

## 目标

让用户能够在大乘 CLI 中完成官方小程序的发现、查看、下载、校验、安装和运行，并形成可复核的端到端闭环。

## 核心范围

- 云端市场浏览与插件详情。
- 官方小程序包或运行入口的获取。
- 下载来源、版本、完整性和安全校验。
- 安装状态、升级状态和错误反馈。
- 安装后运行与基本功能验证。
- 使用测试账号完成真实发布、浏览、下载、安装和运行验证。

## 部署约束

- 每个插件小程序必须作为独立网页部署到 Cloudflare Pages 或 Cloudflare Workers。
- 禁止把插件包或插件静态资源放到 R2 作为市场分发源。
- 插件所需静态资源必须从对应 Cloudflare Pages 或 Workers 服务中获取。

## 非目标

- 不以本地临时文件或仅测试夹具代替真实云端小程序。
- 不以只完成接口单测代替完整安装运行验收。
- 不绕过现有安全校验或信任边界。
