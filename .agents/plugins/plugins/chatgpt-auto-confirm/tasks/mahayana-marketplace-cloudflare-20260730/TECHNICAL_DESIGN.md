# 技术设计：大乘 CLI 云端插件市场

## 架构原则

- 市场元数据、插件网页服务和安装运行契约需要有稳定版本标识。
- 大乘 CLI 负责市场查询、来源校验、版本选择、安全安装和启动。
- 每个插件小程序由独立的 Cloudflare Pages 或 Workers 地址承载。
- 禁止依赖 R2 作为插件包或静态资源分发源。

## 安装链路

1. 从官方市场端点读取插件清单和版本元数据。
2. 校验插件 ID、版本、来源域名和声明的运行入口。
3. 从插件对应的 Pages/Workers 服务获取所需资源。
4. 校验完整性、兼容性和安装目录边界。
5. 原子写入安装状态，失败时不留下半安装状态。
6. 通过大乘 CLI 启动插件并记录可复核结果。

## 安全要求

- 拒绝路径穿越、非法重定向和不可信来源。
- 不允许安装流程覆盖其他插件或 CLI 自身文件。
- 对下载失败、校验失败、版本冲突和启动失败提供明确错误。
- 安装、升级和卸载操作应保持幂等或具备可恢复机制。

## 验证策略

- 以 GitHub Actions 日志、部署地址、市场返回结果和真实安装运行结果为证据。
- 必须至少验证一个真实部署的小程序，不得只使用 mock。
