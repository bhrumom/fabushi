# Fabushi Design Usage

## Read Order
Read `DESIGN.md`, then `tokens.css`, then the task-specific craft references and Skill.

## Design Highlights
Keep Messenger primary, make Agent execution observable, and render generated artifacts as real files with safe preview/open/export actions.

## Do
Use semantic tokens; preserve platform-native interaction; derive runtime motion from real events; keep MiniApps capability-bound.

## Avoid
Do not invent raw colors per component, duplicate navigation shells, create fake progress, or expose arbitrary local files to generated HTML.
