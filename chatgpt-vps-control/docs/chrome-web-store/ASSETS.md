# Chrome Web Store asset checklist

Prepare final production artwork before submission. Keep source artwork in the Fabushi design system; place only approved raster exports in the store upload workflow.

Required/expected listing assets to prepare and review:

- Extension icon set suitable for Chrome/manifest use, including 16, 32, 48, and 128 px PNG exports.
- Store listing icon: 128 × 128 PNG.
- At least one real product screenshot showing the Fabushi Chrome app; recommended 1280 × 800 or 640 × 400, with no mock data that implies unavailable functionality.
- Additional screenshots covering Chats, Mini Apps, Marketplace/search, and a loading/empty/status state.
- Small promotional tile if used by the listing: 440 × 280.
- Marquee promotional tile only if requested/used: 1400 × 560.
- Approved Fabushi name, short description, detailed description, support URL/email, homepage, and privacy-policy URL.

Before upload, verify all screenshots come from the packaged production extension, contain no credentials/private user content, and match the currently submitted version.

Current repository gap: final brand-approved PNG icon assets and production screenshots are not committed by this task and require human/design approval.
