# Chrome Web Store asset checklist

Prepare final production artwork before submission. Keep source artwork in the Fabushi design system; upload only approved raster exports and screenshots captured from the submitted production package.

## Required listing assets

- Store icon: **128 × 128 px**.
- Screenshots: **at least 1, up to 5**, each **1280 × 800 px** (preferred) or **640 × 400 px**, square corners and full bleed.
- Small promotional tile: **440 × 280 px**, PNG or JPEG.

## Recommended extension icon exports

For the packaged extension/Chrome UI, keep square PNG exports at **16, 32, 48 and 128 px** when brand-approved icon files are available. The store uses the 128 px artwork; Chrome can use smaller sizes in browser UI.

## Optional promotional asset

- Marquee promotional image: **1400 × 560 px**.

## Fabushi first-class Chrome screenshot set

Use real production captures that make clear this is **Fabushi for Chrome**, not the legacy ChatGPT-only control extension. Prefer this five-image set:

1. Fabushi **Chats** with the desktop account shown as connected/reused and no second login form.
2. **Mini Apps** and **Marketplace** showing the same Fabushi product surfaces as desktop.
3. **Browser** surface listing ordinary tabs from the user's current Chrome and showing the Fabushi browser bridge connected.
4. **Settings** surface showing desktop-session ownership plus the **Open desktop settings** handoff.
5. A real end-to-end state after the extension has connected to the desktop Host, or a responsive-width capture if it communicates the product more clearly.

Do not use screenshots of the legacy userscript marketplace as the primary store representation. Do not use mock data that implies unavailable functionality. Before upload, verify screenshots come from the exact packaged submitted version, contain no credentials/private user content, and match current desktop Fabushi branding.

Also prepare the approved Fabushi name, short description, detailed description, category/language, support contact, homepage/support URLs and public privacy-policy URL. Store copy should describe the two user-visible purposes accurately: a Fabushi workspace in Chrome and a secure local bridge to the signed-in Fabushi desktop app/current Chrome browser.

Current human/design gate: final brand-approved raster icon/promotional artwork and real production screenshots must be exported/uploaded in the Chrome Web Store Developer Dashboard. They are intentionally not fabricated by the packaging script.
